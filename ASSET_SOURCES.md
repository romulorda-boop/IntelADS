# Mídias ilustrativas do MVP

As imagens abaixo foram selecionadas em busca de imagens e copiadas para `apps/web/public/mock-media/` para representar criativos mock no preview. Não são dados coletados nem sincronizados pela aplicação; anunciantes, campanhas, scores e métricas do seed são simulados. Os arquivos foram mantidos no formato baixado para esta demonstração. Antes de usar em produto público/comercial, revisar direitos/licenças ou substituir por assets licenciados.
